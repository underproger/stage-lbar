### 2.3 Настраиваем идентификатор клиентов OAuth 2.0

![](https://file.modx.pro/files/8/c/e/8ce4517259cd9485cb47ce36a1c37196.jpg)

```
    Имя:
    Название вашего приложения
    
    URI:
    https://site.ru/manager/?a=home&namespace=googlesheets
    site.ru - ваш домен.
```

### 2.4 Создаем приложение

![](https://file.modx.pro/files/e/1/a/e1a7aee060a7a473cb97e8df39eacd01.jpg)

### 2.5 Копируем ключи в системные настройки

 - Идентификатор клиента (googlesheets_client_id)
 - Секретный код клиента (googlesheets_client_secret)

## 4. Авторизация

- Переходим в меню компонента: Приложения -> GoogleSheets
- Нажимаем на кнопку справа **Авторизация**
- Открывается новая вкладка для получения кода авторизации(если не открылась, значит всплывающие окна заблокированы, разблокируйте их)
- Разрешаем доступ приложению
